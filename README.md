## About Me

React와 TypeScript를 기반으로 실무형 프론트엔드 구조를 설계하고 구현하는 개발자입니다.

단순히 화면을 구현하는 것보다, 요구사항이 늘어나도 유지보수하기 쉬운 구조를 만드는 데 관심이 많습니다.  
특히 Admin, Dashboard, 검색/필터 UI, 상태 관리, 권한 제어, 성능 최적화처럼 실무에서 자주 반복되는 문제를 구조적으로 정리하는 것을 중요하게 생각합니다.

최근에는 서버 상태와 UI 상태를 명확히 분리하고, URL State, Feature-based Architecture, Framework-agnostic Core Design 같은 설계 방식을 프로젝트로 실험하고 정리하고 있습니다.

### Virtualized Feed UI

대용량 리스트 렌더링 성능 개선을 실험한 프로젝트입니다.

50,000개 아이템을 기준으로 일반 렌더링 방식의 병목을 재현하고, `@tanstack/react-virtual`을 적용한 최적화 방식과 비교합니다.  
단순히 성능 개선 코드를 적용하는 것에서 그치지 않고, 왜 빨라졌는지 설명할 수 있는 구조를 목표로 했습니다.

**Key Points**
- Large List Rendering
- Virtualization
- Baseline / Optimized 비교
- Rendering Performance 분석
- Scenario-based Project Structure

**Tech Stack**  
`React` `TypeScript` `Vite` `TanStack Router` `@tanstack/react-virtual` `Tailwind CSS`

Repository: https://github.com/yyyys2/virtualized-feed-ui

### Searchable Data Explorer

URL State 기반의 검색, 필터, 정렬, 페이지네이션 UI를 구현한 프로젝트입니다.

URL을 상태의 Source of Truth로 사용하여 새로고침, 공유 링크, 브라우저 히스토리 이동 시에도 동일한 화면 상태를 재현할 수 있도록 설계했습니다.  
또한 핵심 도메인 로직을 React에 강하게 묶지 않고 `packages/core`로 분리하여, 다른 UI 프레임워크에서도 재사용 가능한 구조를 지향했습니다.

**Key Points**
- URL State Architecture
- URL = Source of Truth
- Search / Filter / Sort / Pagination
- Core / Adapter / View Layer 분리
- Framework-agnostic Core Design
- 기본값 제거를 통한 깔끔한 URL 유지

**Tech Stack**  
`TypeScript` `Zod` `React` `Vite` `TanStack Router` `Tailwind CSS` `Vitest`

Repository: https://github.com/yyyys2/searchable-data-explorer
